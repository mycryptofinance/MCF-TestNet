📝 Описание Проекта MCF MyCryptoFinance! Это децентрализованное приложение (DApp) представляет собой комплексную платформу для взаимодействия с токеном MCF (MyCryptoFinance), управления стейкингом и минта NFT.

Приложение поддерживает несколько тестовых сетей, позволяя пользователям покупать токены MCF, стейкать их с различными планами блокировки и минтить уникальные NFT за токены MCF.

Основные Функции. Minting MCF: Пользователи могут обменивать нативные токены сети ETH/BNB на токены MCF.

NFT Minting: Минт эксклюзивных NFT-изданий, каждое из которых имеет фиксированную стоимость в токенах 
MCF
.Flexible Staking: Стейкинг токенов 
MCF
 с различными планами блокировки (гибкий, 7, 30 и 90 дней) и соответствующей годовой процентной доходностью APY.

Multi-Chain Support: Поддержка работы в нескольких блокчейн-сетях.

Wallet Integration: Простое подключение через MetaMask и отображение балансов.

Поддерживаемые Сети (Testnets) DApp настроено для работы со следующими тестовыми сетями и динамически адаптирует адреса контрактов и тикеры нативных валют.
